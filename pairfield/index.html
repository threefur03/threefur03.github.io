Core contributions

PAIRFIELD connects continuous interaction fields with directed, inspectable relations. A single ordered class-pair kernel produces a cycle-frozen anisotropic force for each neighbour. The force norm defines edge salience, and the vector sum forms the nominal social cue, giving an exact force-to-edge correspondence before command saturation and filtering.

Offline calibration distils class-asymmetric signatures into compact parameter tables. Planar linear-forecast control evaluates the exported class-pair tables analytically. CARLA uses a learned-graph predictor. A goal-ray commit gate, go/creep governor and CBF-QP connect these cues to motion. Controlled planar tests isolate class-conditioned passing and bottleneck execution; CARLA integration configurations and mapless ROS 2/LIMO recordings extend evaluation to physical tracking and onboard observations.

Method

Framework

Interaction risk depends on who approaches, in which direction and along which future path. PAIRFIELD represents these distinctions through ordered receiver/source classes and body-aligned anisotropy. Its gradient supplies pairwise social cues and directed edge salience; future positions supply an anticipatory cue. Coordinate-frame choices and forecast backends are declared with each experimental configuration.

Road execution projects interaction cues onto the assigned route and regulates target speed within that route. A CBF-QP filters the shaped reference before tracking.

Controlled evaluation

Planar mechanisms and constrained-space navigation

Planar simulation separates passing geometry, anticipation and wait/recommit control under known agent states.

One method family, two forecast configurations: PAIRFIELD (linear forecast) uses constant-velocity extrapolation; PAIRFIELD (graph forecast) uses the learned interaction graph. The primary planar suite uses linear forecasts. CARLA's source-body experiments use the learned graph predictor.

Performance varies by layout. The tests below separate class-conditioned passing geometry from the wait/recommit controller's constrained-passage behavior; complete baseline and ablation results remain expandable.

Mapless ROS 2 / LIMO navigation

Following controlled planar tests and closed-loop CARLA evaluation, the LIMO deployment connects onboard sensing, field evaluation and physical motion without a prior map.

From tracked observations to local control

The ROS 2 bridge uses odometry, LaserScan geometry and tracked agents in the local frame. LIMO queries a receiver-aligned class-pair parameter export with optional linear forecasts. A speed governor and soft dynamic-agent / hard static-obstacle QP produce bounded Twist commands through the observed differential-drive interface.
