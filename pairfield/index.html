Abstract

Navigation among pedestrians, cyclists and vehicles requires collision avoidance, considerate passing distances and efficient shared motion. PairField represents heterogeneous interactions with an ordered class-pair potential aligned to each source agent's body frame. Its gradient supplies features to a directed prediction graph and current/future navigation cues. A route-constrained interface and barrier-based filter connect these cues to physical tracking. Evaluation spans planar simulation, closed-loop CARLA recordings and a qualitative ROS 2/LIMO hardware adaptation.

Method

Framework

PairField learns an ordered receiver/source class-pair potential in each source body's coordinate frame. Its longitudinal axis follows that agent's heading. The field gradient informs graph prediction and current navigation; predicted positions supply an anticipatory cue.

Road execution projects interaction cues onto the assigned route and regulates target speed within that route. A CBF-QP filters the shaped reference before tracking.

Planar proof of concept

The simpler simulator exposes fields and graph interactions directly. CARLA adds simulated sensing, native traffic response and physical tracking.

ROS 2 / LIMO hardware adaptation

The ROS 2/LIMO adaptation connects onboard observations to bounded differential-drive commands using an exported class-pair field and optional constant-velocity anticipation.

From tracked observations to local control

The ROS 2 bridge uses odometry, LaserScan geometry and tracked agents in the local frame. An exported class-pair field, optional constant-velocity anticipation, speed governor and soft dynamic-agent / hard static-obstacle QP produce bounded Twist commands for the observed differential-drive configuration.
